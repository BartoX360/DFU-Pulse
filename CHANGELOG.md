# Changelog

The update window shows the latest entries, so write them for people using the app.

## 0.6.2

- iPhone and iPad models are listed newest first, and iPads are grouped by line: Pro, Air, iPad and mini.
- The update window now shows what changed in each version.

## 0.6.1

- The port guide covers the 14-inch MacBook Pro with M6, whose DFU port is the one closest to the front.

## 0.6.0

- DFU Pulse now updates itself from GitHub releases. Turn it off or check by hand in Settings.

## 0.5.3

- Every new version is signed, notarized and published automatically.

## 0.5.2

- A restore cannot start without enough free space, even from a window opened earlier.

## 0.5.1

- A restore is blocked when the disk is too full to unpack the image.

## 0.5.0

- An optional helper puts a Mac into DFU without asking for an administrator password each time.
- The app is signed with a Developer ID and notarized by Apple.

## 0.4.0

- iPhones and iPads can be restored too, with any iOS or iPadOS version Apple still signs.

## 0.3.2

- Lighter progress animation.

## 0.3.1

- New app icon.

## 0.3.0

- A short welcome on first launch.

## 0.2.0

- The library lists the Macs each macOS version supports.

## 0.1.0

- First release: revive or restore a Mac in DFU mode.
